Conceal pool API

Public, read-only JSON API. Amounts are atomic units (1 CCX = 1,000,000 atomic units). Everything not listed here is closed. Payments are currently dry-run only until a real block matures and the first payout is verified end to end, so /api/get_payments is legitimately always empty for now. Публичный JSON API только для чтения. Суммы указаны в атомарных единицах (1 CCX = 1 000 000 атомарных единиц). Всё, чего нет в списке, закрыто. Выплаты сейчас только в тестовом режиме, пока не созреет настоящий блок и не будет проверена целиком первая выплата, поэтому /api/get_payments сейчас всегда пуст — это ожидаемо.

MethodsМетоды

GET /api/stats
Pool and network statistics: hashrate, miners, workers, blocks, network difficulty and height, last block with its reward, pool settings (fee, minimum payout).
Статистика пула и сети: хешрейт, майнеры, воркеры, блоки, сложность и высота сети, последний блок и его награда, настройки пула (комиссия, минимальная выплата).
/api/stats
GET /api/stats_address?address=ADDRESS&longpoll=false
Statistics of one miner: hashrate, shares, pending balance, workers, payments. ADDRESS is the bare Conceal address your miner logs in with (the part before +workername, if any) -- do not include the worker name.
Статистика одного майнера: хешрейт, шары, баланс к выплате, воркеры, платежи. ADDRESS это адрес Conceal из логина майнера (часть до +имя_воркера, если оно есть) -- без имени воркера.
/api/stats_address?address=ccx7PT3VrsbUHbFugUnGTJVZ58n8RrSZuSL3TWhL4iSAez6LL7QKKER42nkA4gJay1dKqRn5zSEkXYkSD1gBrwCq6Vj1Vs9RQV
GET /api/get_payments?time=UNIX_MS&address=ADDRESS
Latest payments (older than time, milliseconds), pool-wide or for one address. Always empty right now: see the dry-run note above.
Последние платежи (старше time, миллисекунды), по всему пулу или по одному адресу. Сейчас всегда пусто: см. примечание про тестовый режим выше.
/api/get_payments
GET /api/get_blocks?height=HEIGHT
Blocks found by the pool (below height): time, finder, hash, difficulty, shares, orphaned flag, reward.
Блоки, найденные пулом (ниже height): время, нашедший, хеш, сложность, шары, флаг orphaned, награда.
/api/get_blocks
GET /api/get_top10miners
Top 10 miners by live hashrate; addresses are shortened.
Топ-10 майнеров по текущему хешрейту; адреса сокращены.
/api/get_top10miners
GET /api/block_explorers
Block/transaction explorer URL templates: explorer.conceal.network.
Шаблоны ссылок на обозреватель блоков/транзакций: explorer.conceal.network.
/api/block_explorers

ExampleПример

curl https://conceal.pool-pay.com/api/stats
